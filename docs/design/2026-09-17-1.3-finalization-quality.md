# 1.3.0 source-integration verification

Version: **1.3.0**, build **25**. This report concerns the authorized source PR;
it does not authorize or announce a Tag or GitHub Release.

## Boundaries

- Work is confined to the public feature workspace. The private archive is untouched.
- UI fixtures run in the disposable Debug Validation application with synthetic
  data, service-less models, and in-memory preferences. No production folder
  preferences are seeded, cleared, or migrated.
- Existing Self Training memberships and stable IDs retain their compatibility
  tests. The new-install empty folder is not an upgrade reset.
- Capability package manifest v1, cache schema v1, and rollout parser version
  remain unchanged.

## Core journeys

- Entry search: matching installed Skill, no-result state, clear-search return.
- Folder search and tabs: complete Agent/Skill lists, Skill filtering, independent
  tab searches, returning to the prior search, and keyboard-selected usage sort.
- Companions: initial disclosure, declared Skill preview, Skill-to-Agent detail
  navigation in the same sidebar, and explicit separation from shared-session evidence.
- Project scope: a project Agent can preview a global Skill while project counts
  remain one Agent and zero Skills. Preview-only relationship labels are distinct
  from the member count.
- Add existing: two staged checkbox selections create one Agent/one Skill member
  set in the synthetic Self Training folder; theme/refresh-state changes retain it.
- Theme and refresh: Settings switches to Light immediately; synthetic loading
  shows native progress, disables refresh, preserves content, and returns to idle.
- Chinese/English and Light/Dark native layouts were inspected at desktop and
  compact sizes. The host reports 720×480 for its compact product viewport and
  1280×748 with its controls visible on this display; capture mode was separately
  inspected at the requested 1280×800 product size.

Runtime checks exposed native text-editor layout re-entry when clearing entry
search or changing a folder tab. Both responsive search layouts now instantiate
one editor rather than competing ViewThatFits candidates. The previously failing
actions were repeated successfully, with source-contract regressions added.

## Quota correction

not new resets. They no longer replace the accepted forward-cycle observation.
Domain and SQLite projection regressions cover the sequence previously producing
224%, now producing 62%. Real forward reset cycles are not clamped to 100%.
